# harbringer rules

- dashboard_has_next: when I've watched an episode, the dashboard in plex etc must show the next episode to watch

## harbringer web
- no_the: don't sort using "the" when showing a library
- search_media: navbar with search up top: we need to be able to search all media. this search bar should be omnipresent. search results should display as typed
- no_doubles: don't show double episodes
- spa: the webpage should be a single page app driven by javascript to prevent load time
